🚀 Sakneen Frontend Task

This is the frontend project for the Sakneen task.
It is built with:

⚛️ React + Next.js + TypeScript

🎨 TailwindCSS for styling

🎠 SwiperJS for carousels

🖼 Lucide React & React Icons for icons

🎛 Headless UI for accessible UI components

📦 Prerequisites

Make sure you have the following installed:

Node.js ≥ 18

npm ≥ 9

⚙️ Installation

Clone the repository and install dependencies:
git clone <your-repo-url>
cd <your-project-folder>
npm install

Then install required libraries:
# Icon libraries
npm install lucide-react react-icons

# Helpers
npm install @swc/helpers

# UI components
npm install @headlessui/react

# Development tools
npm install --save-dev json-server @types/jsdom


▶️ Running the Project

Start the development server:
npm run dev
The app will be available at:
👉 http://localhost:3000

🧪 Testing

This project uses Jest for testing. Run tests with:
npm run test


📌 Notes

TailwindCSS → Utility-first CSS framework used across the project.

SwiperJS → Handles image and content carousels.

Lucide React / React Icons → Provide icon components.

Headless UI → Pre-built accessible components.

JSON Server → Mock backend APIs during development.
